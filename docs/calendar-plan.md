# Календарный план проекта

Источник: предоставленный пользователем фрагмент календарного плана.

## Этап 2

- Продолжительность: 11 месяцев.
- Период: с 14.12.2025 по 13.11.2026.
- Аванс: 900 000 руб.
- Аванс оплачен: 19.11.2025.

### Состав работ

1. Разработка дизайна пользовательских интерфейсов онлайн-платформы.
2. Разработка пошаговых руководств и рекомендаций по безопасному и эффективному использованию сервиса арендодателями и арендаторами.
3. Разработка frontend- и backend-частей для онлайн-платформы.
4. Создание базы данных для хранения и обработки информации на онлайн-платформе.
5. Создание сайта стартап-проекта.
6. Интеграция онлайн-платформы на сайт стартап-проекта.
7. Проведение рекламной кампании стартап-проекта.

> Примечание: документ фиксирует данные календарного плана и сам по себе не отражает фактический статус выполнения перечисленных работ.
